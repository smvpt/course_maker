# Как читать аббревиатуры и обозначения — геология

Источник: заготовка организаторов «словарь ударений и произношений» (04_доменные_заготовки), дополняется по главам.

При первом упоминании аббревиатура раскрывается словами, дальше читается по таблице. Буквы, записанные через пробел, голос обычно произносит раздельно.

| ПС | пэ эс | потенциалы самопроизвольной поляризации |
| ГК | гэ ка | гамма-каротаж |
| НГК | эн гэ ка | нейтронный гамма-каротаж |
| ННК | эн эн ка | нейтрон-нейтронный каротаж |
| ГГК-П | гэ гэ ка пэ | гамма-гамма-каротаж плотностной |
| АК | а ка | акустический каротаж |
| КС | ка эс | кажущееся сопротивление |
| БК | бэ ка | боковой каротаж |
| ИК | и ка | индукционный каротаж |
| БКЗ | бэ ка зэ | боковое каротажное зондирование |
| МКЗ | эм ка зэ | микрокаротажное зондирование |
