# ИТ-мосты — геология

Аналогии для читателя с ИТ-опытом. У каждой — где она перестаёт работать: без этой границы аналогия запрещена (категория ошибки `analogy_without_limit`). Составлено ИИ-ассистентом П2; спорное — к ментору.

| Геология | ИТ-аналогия | Где ломается |
| --- | --- | --- |
| Каротажная кривая — отклик прибора, свойство пласта получают интерпретацией | Сырые логи сервиса против бизнес-метрики, вычисленной из них | Связь «сигнал → свойство» задаёт физика и калибровка по керну, а не схема данных; одна кривая неоднозначна без других методов |
| Граничное значение (кондиция) коллектора | Порог классификатора | Порог выводится из физики притока и экономики и переносится на геопараметры по корреляциям с потерей точности, а не подбирается на валидации |
| Смена типа разреза (терригенный → карбонатный) | Сдвиг распределения (domain shift) | Сдвиг физический и известен заранее по геологии; его не обнаруживают по данным, а учитывают до интерпретации |
| Палетка — номограмма поправок | Таблица поиска (lookup table) с интерполяцией | Палетка рассчитана для модели пласта и скважины; вне её допущений поправка неверна, а «таблица» об этом не сообщает |
| Зона проникновения фильтрата | Кэш, перекрывающий данные основной базы рядом с точкой чтения | Глубина «кэша» зависит от проницаемости и времени, со временем меняется; читать «за кэшем» помогают зонды разной глубинности |
| Переходная зона над ВНК | Плавное, а не ступенчатое переключение состояния | Ширина зоны задаётся капиллярными силами и размером пор; резкой границы, как у флага, нет |
| Волна давления в пласте (пьезопроводность) | Распространение изменений с задержкой, как eventual consistency | Давление расходится диффузионно: радиус влияния растёт как √t, а не с постоянной скоростью, как пакеты в сети |
| Повторные замеры (временные ряды ГИС) | Сравнение снапшотов состояния | Между замерами меняются и пласт, и скважина (корка, проникновение); разница — не только изменение насыщения |
| Корреляция разрезов скважин | Сопоставление записей из разных источников по ключу (entity resolution) | Ключа нет: сопоставляют по форме кривых и геологическим реперам, и ошибка накапливается между скважинами |
| Модель залежи | Цифровой двойник | Двойник опирается на редкие точки (скважины) и интерполяцию; «под землёй» модель не знает, это гипотеза с неопределённостью |
| Петрофизическая связь по керну | Регрессия, обученная на размеченной выборке | Разметка (керн) дорогая и смещённая: керн берут не везде, и связь неприменима вне изученного типа пород |
| Седиментационная модель (фации, проградация) | Генеративная модель, объясняющая, как возник наблюдаемый набор данных | Процессы известны качественно; параметры по одной скважине не восстанавливаются однозначно |
