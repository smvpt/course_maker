# Тестовый пакет для модуля проверки

Черновик учебного материала по главе Asquith (`asquith_ch7.md`) с заложенными ошибками. Формат тот же, что у контрольного пакета: `package.json` по схеме `review_package.schema.json`, кадры — в папке `frames`.

Что сделать:

1. Запустите свой модуль проверки на `package.json`.
2. Сохраните ответ по схеме `review_output.schema.json`: одно замечание на цель — `target`, `category`, `severity`, `problem`, `fix`, `page_pdf`.
3. Положите ответ в репозиторий и сдайте до 14:00 вместе с остальным тестом.

Страницы — по меткам `<!-- page N -->` в `asquith_ch7.md`. Ключ к этому пакету не выдаётся: результат считают организаторы тем же скриптом `score_review.py`, что и для контрольного пакета.
