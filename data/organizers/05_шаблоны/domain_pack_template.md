# Шаблон доменного пакета

Движок конвейера не должен знать геологии: всё предметное лежит в доменном пакете. Для нового домена (например, бурения) собирается новый пакет, а код не меняется.

```
domain/
  geology/
    glossary.md            # термины RU/EN: термин, определение, западный аналог
    misconceptions.json    # заблуждения: id misc.*, текст
    physics_checklist.json # чек-лист корректности: id pc.*, группа, вопрос
    it_bridges.md          # ИТ-аналогии и где они ломаются
    styleguide.json        # цвета пород, флюидов, кривых, метки происхождения
    pronunciation.md       # как читать аббревиатуры и обозначения
    stress_dictionary.md   # ударения в терминах
    errata/                # листы опечаток распознавания по главам
    templates/             # шаблоны сцен по типам трудности (М, В, И, Ф, П, Пр, Н, Р)
  drilling/
    ...                    # та же структура для другого домена
```

Что оценивается: пакет отделён от кода; для нового домена записано, сколько времени занял пакет и какие шаблоны сцен подошли без изменений.
