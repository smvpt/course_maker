# Шаблоны для сдачи

## Журнал ручных правок — `manual_edits.csv`

Ведётся на тесте: любая правка результата после сырого прогона конвейера, в том числе сделанная через ИИ-ассистента. Одна строка — одна правка. Первая строка после заголовка — пример, её удалите.

| Поле | Что писать |
| --- | --- |
| `time` | Время правки, ISO: 2026-12-02T10:15 |
| `chapter` | Идентификатор главы |
| `file` | Какой файл изменён |
| `what_changed` | Что изменено |
| `person_minutes` | Человеко-минуты: два человека по 10 минут — 20 |
| `people` | Сколько человек правило |
| `run_no` | Номер прогона конвейера, результат которого правили |
| `reason` | Почему понадобилась правка |

## Метрики — `metrics.csv`

Одна строка на главу и этап (`layer`, `routing`, `course`, `video`, `review`): число узлов, токены и деньги на модели, человеко-минуты, минуты ментора, секунды готового видео, доля ручного труда. Из таблицы считаются стоимость узла, главы курса и минуты видео.

## Манифест конвейера — `MANIFEST.md`

Каждый инструмент и каждая модель с версией и пометкой, уходят ли данные во внешний сервис. Пример — в `MANIFEST_template.md`.

## Доменный пакет — `domain_pack_template.md`

Структура папки доменного пакета: что в нём лежит и как движок его подключает.
