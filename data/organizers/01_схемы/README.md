# Схемы и форматы

Общие для всех команд форматы. Они нужны, чтобы модули разных команд были совместимы: слой одной команды можно проверить модулем другой, а курс собрать из слоя третьей. Поля сверх схемы добавлять можно, убирать обязательные — нельзя.

| Файл | Что описывает | Раздел ТЗ |
| --- | --- | --- |
| `node.schema.json` | Учебный слой главы: узлы, утверждения с цитатой и страницей, связи, «что это значит для данных», ИТ-аналогия, разобранные примеры и задачи книги | Задание, часть 1 |
| `example_layer.json` | Пример слоя из одного узла, написан вручную | — |
| `coverage.schema.json` | Таблица покрытия: каждая единица главы → узел или причина | Задание, часть 1 |
| `routing.schema.json` | Маршрутизация: формат каждого узла, критерии видеоёмкости, обоснование | Задание, часть 2 |
| `task.schema.json` | Задания курса: пять типов, ключ, пояснение, ссылка на утверждение | Задание, часть 3 |
| `illustration.schema.json` | Иллюстрации курса: класс кадра, как сделана, метка, подпись | Визуальная часть курса |
| `passport.schema.json` | Паспорт ролика: сценарий, источники, спецификация сцены, классы кадров | Задание, часть 4 |

Формат внешнего пакета для модуля проверки — в папке `02_модуль_проверки`.

Главное, что проверяется по схемам:

- `page_pdf` — номер страницы из метки `<!-- page N -->` в выданном md главы.
- `quote` — дословная цитата из выданного md; при сверке не учитываются пробелы, переносы строк и регистр.
- `by_model: true` — поле написано моделью, а не взято из книги.
- `kind` утверждения: `observation` — наблюдение, `inference` — вывод, `assumption` — допущение.
- Связи: `prerequisite` — предпосылка, `example_of` — пример, `refutes_misconception` — опровергает заблуждение, `to_data` — переход к данным.
- Типы трудности: М, В, И, Ф, П, Пр, Н, Р — как в документе «Подача доменов геологии».

Проверить файл по схеме:

```
pip install jsonschema
python -c "import json,jsonschema; jsonschema.validate(json.load(open('layer.json',encoding='utf-8')), json.load(open('node.schema.json',encoding='utf-8'))); print('ok')"
```
