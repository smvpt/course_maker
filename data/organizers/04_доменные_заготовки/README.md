# Заготовки для доменного пакета

Это стартовые материалы, а не готовый доменный пакет. Доменный пакет каждая команда собирает сама: глоссарий RU/EN, заблуждения, чек-лист физики, ИТ-мосты, стайлгайд, словарь ударений и произношений. Его качество и отделённость от кода оцениваются.

| Файл | Что внутри |
| --- | --- |
| `misconceptions.json` | Типичные заблуждения неспециалистов с id (`misc.*`) — на них ссылаются связи `refutes_misconception` и неверные варианты заданий |
| `physics_checklist.json` | Чек-лист физической и предметной корректности из ТЗ в машиночитаемом виде (`pc.*`) |
| `словарь_ударений_и_произношений.md` | Заготовка: как читать аббревиатуры и обозначения, ударения в частых терминах |
| `портреты_зрителя.md` | Три портрета зрителя и их рабочие ситуации |

Легенда и стайлгайд — в папке `03_стайлгайд`.
