# Пакет вводных хакатона «Глава → курс»

Дополнение к главам, анализам книг и роликам-референсам. Форматы общие для всех команд: не придумывайте свои, иначе модули разных команд не будут совместимы.

| Папка | Что внутри |
| --- | --- |
| `01_схемы` | JSON-схемы учебного слоя, таблицы покрытия, маршрутизации, заданий, иллюстраций и паспорта ролика; пример слоя |
| `02_модуль_проверки` | Формат внешнего пакета и ответа модуля проверки, скрипт подсчёта, контрольный пакет с закладками и ключом для самопроверки |
| `03_стайлгайд` | Легенда цветов и конвенции: `styleguide.json` и `legend.html` |
| `04_доменные_заготовки` | Заблуждения, чек-лист физики, словарь ударений и произношений, портреты зрителя |
| `05_шаблоны` | Журнал ручных правок, метрики, манифест конвейера, структура доменного пакета |
| `06_подача_и_референсы` | «Подача доменов геологии»: восемь типов трудности, формат-микс, карта 48 концептов; разборы четырёх роликов-референсов |

Тестовый пакет для модуля проверки выдаётся на этапе теста, после заморозки, без ключа.
