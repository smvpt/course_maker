# Модуль проверки: формат внешнего пакета

Модуль проверки получает чужой черновик учебного материала по главе и ищет в нём ошибки. На тесте каждая команда получит пакет по тестовой главе с заложенными ошибками; сейчас выдан контрольный пакет с ключом для самопроверки.

## Что на входе

`review_package.schema.json` — пакет по одной главе:

- `items` — всё, что нужно проверить, у каждого элемента свой `id`:
  - `claim` — утверждение с типом (наблюдение, вывод, допущение), страницей `page_pdf` и цитатой `quote`;
  - `analogy` — ИТ-аналогия и где она перестаёт работать;
  - `script_line` — фраза закадра ролика с таймкодом и ссылкой на утверждение;
  - `scene_fact` — факт из спецификации сцены, сформулированный словами;
- `scenes` — спецификации сцен целиком, как контекст;
- `frames` — 8–12 кадров роликов (PNG) с заявленным классом кадра, меткой происхождения, описанием и плашкой.

Страницы и цитаты сверяются с md главы, который у вас уже есть (`chapter_file`).

## Что на выходе

`review_output.schema.json` — список замечаний. Одно замечание на цель:

| Поле | Что в нём |
| --- | --- |
| `target` | `id` элемента или кадра |
| `category` | категория ошибки, см. ниже |
| `severity` | `critical`, `significant` или `minor` |
| `problem` | что не так |
| `fix` | как должно быть |
| `page_pdf` | страница главы, которая подтверждает исправление |
| `quote` | цитата с этой страницы, по желанию |

Категории:

| Код | Ошибка |
| --- | --- |
| `overgeneralization` | Сверхобобщение: «всегда», «любой», где в главе есть условия |
| `sign_flip` | Переворот направления или признака: выше вместо ниже, рост вместо падения |
| `measured_vs_inferred` | Измеренное выдано за выведенное или наоборот |
| `lost_condition` | Потеряно условие применимости |
| `missing_caveat` | Пропущена оговорка автора |
| `wrong_scaling` | Неверный закон масштаба или зависимость: степень, пропорциональность |
| `wrong_mechanism` | Неверный механизм прибора или процесса |
| `outdated_as_current` | Устаревшее выдано за текущую практику |
| `analogy_without_limit` | ИТ-аналогия без границы или с неверной границей |
| `frame_error` | Ошибка кадра или сцены: глубина вверх, газ под нефтью, неверная метка происхождения, неподписанное преувеличение |
| `other` | Другое |

## Как считается

`score_review.py` считает так же, как жюри:

- вес ошибки: критическая — 3, существенная — 2, незначительная — 1;
- находка засчитывается полностью, если в замечании есть исправление и верная страница; наполовину — если цель верная, но нет исправления или страница не та;
- замечание к элементу без ошибки — ложная тревога. В пакете есть верные, но неожиданно звучащие утверждения: замечание к ним тоже ложная тревога.

```
python score_review.py мой_ответ.json контрольный_пакет/key.json
```

Сначала прогоните модуль, потом смотрите ключ.
