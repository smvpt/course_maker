## Что нужно ответить
Верни JSON с полями:
- `feasible`: `true`, если по ОДНОЙ из формул выше можно построить график, используя только числа из узла. Если нельзя (в формуле неизвестные величины, которых нет в узле, или график ничего не объяснит), поставь `false`, остальные поля оставь пустыми.
- `claim_id`: id утверждения-формулы из списка выше.
- `title`: заголовок графика по-русски, до 8 слов: что от чего зависит.
- `x_name`: имя независимой переменной в выражении, латиницей, например `rho_oil`.
- `x_label`, `x_unit`: подпись оси по-русски и единица (может быть пустой).
- `y_label`, `y_unit`: то же для результата формулы.
- `x_min`, `x_max`: диапазон независимой переменной, `x_min` меньше `x_max`. Диапазон должен быть физически осмысленным и, если узел называет пороги или значения, охватывать их.
- `constants`: остальные величины формулы: имя на латинице → число. Каждое число должно быть записано в узле (в утверждениях, примерах или тексте). Других чисел брать нельзя.
- `expression`: выражение для результата формулы через `x_name` и `constants`. Разрешены числа, `+ - * / **`, скобки и функции `sqrt`, `log`, `log10`, `exp`. Все переменные из `constants` и `x_name` должны в нём использоваться. Числовые константы формулы, которых нет в узле, допустимы только из набора 1, 2, 3, 4, 5, 10, 100.
- `depth_axis`: `"x"`, если независимая переменная — глубина; `"y"`, если результат — глубина; иначе `"none"`. Глубина на графике всегда будет по вертикали и расти вниз.
- `curve_key`: ключ кривой из легенды или `null`.
- `note`: одна фраза по-русски: что показывает график.

## Правила
1. Ничего сверх узла: не выдумывай числа, формулы и факты.
2. Выражение должно давать конечное число при каждом значении `x_name` из диапазона и меняться (не быть константой).
3. Весь текст на русском.
