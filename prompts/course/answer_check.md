## Что нужно сделать
Верни JSON `{"picks": [...]}`, по одному элементу на каждое задание, в том же порядке. Поля:
- `n`: номер задания.
- `answer`: список строк.
  - `single` — id одного верного варианта.
  - `multiple` — id всех верных вариантов.
  - `order` — id всех элементов в том порядке, в котором они верны по цитате (первый — первый по смыслу).
  - `gap` — слова для пропусков `{{1}}`, `{{2}}` … по порядку, ровно так, как они написаны в цитате.
- `claim_id`: id утверждения, по цитате которого ты ответил.
- `evidence`: фраза, ДОСЛОВНО скопированная из цитаты этого утверждения (3–15 слов), на которой держится ответ. Не пересказывай и не исправляй: пробелы и регистр не важны, слова должны совпадать.

## Правила
1. Отвечай только по цитатам выше. Свои знания о предмете не используй: если цитата называет одно, а ты «знаешь» другое, прав автор.
2. Выбирай тот вариант, который прямо подтверждает цитата. Если по цитатам ни один вариант не подтверждается, всё равно выбери ближайший и в `evidence` дай ту фразу, из-за которой сомневаешься.
3. Не придумывай `claim_id`: бери только из ключей выше.
