## Что нужно ответить
Верни JSON с полями:
- `feasible`: `true`, если по ОДНОЙ из формул выше можно построить такой интерактив, используя только числа из узла. Если нельзя, поставь `false`, остальные поля оставь пустыми.
- `claim_id`: id утверждения-формулы из списка выше.
- `title`: заголовок интерактива по-русски, до 8 слов: что от чего зависит.
- `slider_name`: имя переменной слайдера в выражении, латиницей (например `t` или `depth`).
- `slider_label`, `slider_unit`: подпись слайдера по-русски (например «Время») и единица (может быть пустой).
- `slider_min`, `slider_max`: диапазон слайдера, `slider_min` меньше `slider_max`. Диапазон должен быть физически осмысленным и охватывать значения и пороги, которые называет узел.
- Только для шаблона distribution: `x_name` (переменная оси x латиницей, отличная от `slider_name`), `x_label`, `x_unit`, `x_min`, `x_max`. Для других шаблонов эти поля оставь пустыми.
- `y_label`, `y_unit`: подпись и единица результата формулы.
- `constants`: остальные величины формулы: имя на латинице → число. Каждое число должно быть записано в узле. Других чисел брать нельзя.
- `expression`: выражение для результата формулы через переменные слайдера (и оси x для distribution) и `constants`. Разрешены числа, `+ - * / **`, скобки и функции `sqrt`, `log`, `log10`, `exp`. Все переменные и константы должны использоваться. Числовые константы формулы, которых нет в узле, допустимы только из набора 1, 2, 3, 4, 5, 10, 100.
- `curve_key`: ключ кривой из легенды или `null`.
- `note`: одна фраза по-русски: что видно, когда двигаешь слайдер.

## Правила
1. Ничего сверх узла: не выдумывай числа, формулы и факты.
2. Выражение должно давать конечное число на всём диапазоне и меняться при движении слайдера.
3. Весь текст на русском.
