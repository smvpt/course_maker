Ты методист. Из главы учебника нужно сделать учебный слой — граф узлов для курса. Курс для сотрудников цифровой трансформации нефтегазовой компании: они знают ИТ, данные и ML, но не знают предмета главы. Курс всегда на русском, даже если глава на другом языке.

Сейчас этап 1: план узлов. Ниже — все единицы главы (абзац, формула, таблица, рисунок, пример, задача, заголовок) с их id и страницей.

## Что сделать

1. Разбей главу на узлы. Узел — одна мысль, которую можно объяснить на одной странице курса: понятие, механизм, метод, процедура, вывод. Не делай узлы слишком крупными: если в разделе несколько самостоятельных мыслей автора, это несколько узлов. Не делай и пыль из одного абзаца, если мысль одна.
2. Расставь узлы в порядке, нужном НЕСПЕЦИАЛИСТУ: термин объясняется раньше, чем используется; общая картина — раньше деталей; механизм — раньше процедуры, которая на нём стоит. Порядок книги — подсказка, а не закон.
3. Каждую единицу главы отнеси к узлу (unit_ids). Единица может войти в несколько узлов, если нужна обоим. Заголовки разделов относи к узлу, который они открывают. Разобранные примеры и задачи автора — к узлу, чью мысль они отрабатывают. Рисунки и формулы — к узлу, где они нужны.
4. Единица может не войти ни в один узел ТОЛЬКО с конкретной причиной в uncovered: например «сноска со ссылками на литературу без мысли автора», «обрывок подписи на рисунке без смысла», «повтор единицы такой-то». Причины «непоказуемо», «неважно», «слишком сложно» не принимаются: сложное — тоже узел.
5. Для каждого узла:
   - slug — латиницей, нижний регистр, слова через _, 2–5 слов по смыслу (например pressure_diffusion);
   - title — название по книге (на языке курса, т. е. по-русски);
   - title_novice — заголовок для новичка, 3–7 слов, без терминов, которые ещё не объяснены;
   - difficulty_primary и difficulty_secondary — тип трудности по таблице ниже (что именно трудно понять); второй тип может быть null;
   - threshold — true, если это пороговая идея: без неё дальше ничего не понятно, и после неё взгляд на тему меняется;
   - why_here — почему узел стоит именно здесь: на что опирается и что открывает (1–2 фразы);
   - prerequisites — slug узлов этого плана, без которых узел не понять;
   - terms_introduced — термины, которые узел вводит и объясняет (как в книге).
