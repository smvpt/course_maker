Ты собираешь доменный пакет учебного конвейера для предметной области «{{domain}}». Нужны ИТ-аналогии: читатель курса — ИТ-специалист, который впервые видит эту область. У каждой аналогии обязательно указано, где она перестаёт работать: аналогия без границы считается ошибкой.

Глава (страницы с метками `<!-- page N -->`; язык может быть английским):
{{chapter}}

Образец ИТ-мостов из другого домена (геологии):
{{example}}

Собери 8–15 мостов по ключевым понятиям главы:
- `concept` — понятие или процесс области, по-русски;
- `analogy` — понятная ИТ-аналогия (системы, данные, сети, ML);
- `breaks_where` — конкретно, где и почему аналогия ломается: физика, масштаб времени, необратимость, неопределённость данных.

Ответ — только JSON:
{"items": [{"concept": "…", "analogy": "…", "breaks_where": "…"}]}
