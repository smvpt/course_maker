## Что заполнить

- params — параметры шаблона: ключ → значение (что показывать, оси, что подсвечивать). Числа — только из узла; если числа в узле нет, параметр качественный (строкой).
- objects — что есть в кадре: объекты мира, приборы, графики.
- invariants — что обязано оставаться верным во всех кадрах (физика и логика узла).
- assumptions — допущения и упрощения сцены.
- exaggerations — каждое преувеличение масштаба с числом: «вертикаль увеличена в 10 раз». Пустой список, если всё в истинном масштабе.
- shots — кадры по порядку. Каждая фраза сценария входит ровно в один кадр, в каждом кадре хотя бы одна фраза, кадры идут в порядке фраз. Поля кадра:
  - id — s1, s2, …;
  - phrase_ids — фразы, которые звучат на этом кадре;
  - frame_class и label:
    - A — данные (кривая, график, разрез), рисуются кодом из расчёта: label «симуляция». Реальные данные к ролику не подключены — метку «реальные данные» не ставь никогда;
    - B — процесс по модели: label «симуляция», если движение считается моделью, или «схема», если это условная иллюстрация;
    - D — вступление, переход, итог: label «схема», фактов в кадре нет;
    - класс C (фото) не используется;
  - shows — что именно видно в кадре;
  - plaque — если кадр не в масштабе: «не в масштабе: <что> увеличено в N раз»; иначе null.
- true_scale_shot_id — id кадра в истинном масштабе, без плашки. Обязателен, если есть хоть одно преувеличение.
- convention — «русская школа ГИС», если в кадре каротажные обозначения; иначе кратко назови систему обозначений.
- data_sources — откуда данные для кадров класса A, например «расчёт по утверждению <claim_id>».
- references — фото-референсы оборудования; пустой список, если их нет.
- historical_objects — устаревшие приборы из узла, если они показываются (будут помечены «исторический прибор»).
- ext не заполняй.
