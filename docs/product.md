# Продукт: чем наш курс выделяется (поверх ТЗ, не вместо)

Приоритеты: 1) ТЗ целиком → 2) надёжность → 3) понятность → 4) фишки ниже → 5) архитектура.
Каждая фишка строится ТОЛЬКО из полей, которые конвейер и так обязан делать по ТЗ. Ни одна не требует сервера, чата или новой модели. Если фишка мешает обязательному — выкидываем фишку.

## Наша позиция в одной фразе
NotebookLM быстро делает материалы по любому документу, но его ссылки на источник не всегда совпадают с тем, что он написал. Практикум хорош активной практикой с подсказкой при ошибке, но его курсы пишут люди месяцами. Наш курс собирается машиной за минуты **и каждое его утверждение проверено по странице книги — это видно и проверяемо в один клик.**

## Что сознательно НЕ делаем
- Чат с книгой — нужен сервер или ключ в браузере, риск выдумок; ТЗ требует курс без сервера.
- Говорящий аватар, генеративные картинки механизмов — прямо «не принесёт мест».
- Веб-интерфейс загрузки главы — нужен сервер; в MVP загрузка = `make all CH=…`, это направление развития.
- Аудиоверсия всех шагов — раздувает размер курса (лимит 30 МБ), риск ударений.

## Путь пользователя
**Оператор (компания):** кладёт md+PDF главы → строка в `config/chapters.yaml` → `make all CH=x` → печатает этапы и итог: «узлов N, покрытие 100%, цитат сверено 98%, замечаний 3, стоимость $X» → открывает `out/x/course/index.html`.
**Новичок:** обложка главы (что узнаю, сколько минут, из каких частей) → шаг: «сначала угадай» → суть в 2 фразах → как это работает (стр. N у абзаца, «проверь по книге») → разбор примеров → ролик/интерактив → «что это значит для данных» → 2–3 задания с подсказкой → дальше. Прогресс и возврат к месту сохраняются. В конце главы — карточки, конспект в PDF, карта связей, «Где здесь ИТ-задачи».

## Развитие после хакатона (для слайда)
Веб-загрузка и очередь глав → прогон по корпусу 300+ книг → доменные пакеты для бурения, добычи, переработки → общий граф знаний между книгами (связи узлов разных глав) → аналитика прохождения (где новички ошибаются → какие узлы переписать) → интеграция с корпоративным LMS через экспорт SCORM.
