# П3 — демо-курс и иллюстрации (роль в команде: педагогика / сценарий)

Сначала прочитай корневой `CLAUDE.md` — там границы и интерфейсы. Твоя зона там же, строка «Курс».
Курс — то, что жюри и панель новичков реально открывают. Он собирается из `layer.json` автоматически, без ручной вёрстки.

## Баллы, за которые ты отвечаешь
Демо-курс (15) + половина «двойников» (30) + понятность для панели новичков.

## Что тебе нужно от других и где взять
- `layer.json`, `routing.json` — образец в `fixtures/core/mini_chapter/` (до появления — свой в `fixtures/course/`, по `contracts/models.py`).
- Ролики — `out/<ch>/videos/<node_id>/*.mp4` (если файла нет — показывай спецификацию/интерактив, не падай).
- Цвета пород, флюидов, кривых — `pipeline.common.domain.load(domain)["styleguide"]` (файл `styleguide.json` организаторов).

## Форматы организаторов (обязательно, см. `CLAUDE.md` §1б)
- Задания — `out/<ch>/course/tasks.json` по `task.schema.json` (`Tasks`): `type` ∈ `single/multiple/order/gap/calc`, `step_id` = id узла, `claim_ids`, `options[{id,text,misconception}]`, `answer` (single — id; multiple/order — список id; gap — список слов, пропуски в `prompt` как `{{1}}`; calc — число + `tolerance`, `unit`), `explanation` одной фразой, `kind`.
- Иллюстрации — `out/<ch>/illus/illustrations.json` по `illustration.schema.json` (`Illustrations`): `origin` ∈ `code_from_data/code_from_model/photo/redrawn_from_book/ai_generated`, `label` на самой картинке, `claim_ids` для A и B; `ai_generated` — только класс C/D, метка «иллюстрация ИИ» и `prompt`.
- Страница шага строится из полей слоя организаторов: «Суть» ← `layers.main` (+ `layers.topic` как подзаголовок), «Как это работает» ← `layers.mechanism` + утверждения, практика ← `layers.practice`, нюансы ← `layers.nuances`, «глубже» ← `layers.deeper`, «Что значит для данных» ← `data_meaning` (гипотезы помечены), «Аналогия» ← `it_analogy`, «Частая ошибка» ← `misconception`, «Решение на данных» ← `decision_on_data`, примеры ← `worked_examples`, задачи ← `book_tasks`. Заголовок для новичка — `title_novice` (поле сверх схемы), название из книги — `title`.
- Цвета, метки и конвенции — только из `styleguide.json` организаторов (`data/organizers/03_стайлгайд/`): русская школа ГИС (ПС, ГК, КС…), глубина вниз, неопределённость — серая штриховка или диапазон, а не одна линия.

## Задачи по порядку

### 1. Шаблон сайта — до 18:00
- Генератор `pipeline/course/build.py --ch [--node]`: Jinja2 → `out/<ch>/course/` (index.html + страницы шагов + assets). Открывается двойным кликом из файла: никаких fetch к локальным JSON (данные встраивать в страницу как `<script type="application/json">`), никаких CDN.
- Путь: части и шаги в порядке графа, время на шаг, прогресс и «вернуться туда, где остановился» (localStorage в try/catch).
- Страница шага — все блоки ТЗ, пустые не показываются: заголовок для новичка + название из книги, суть, как это работает, по шагам, разбор примеров, цифры и условия, новые понятия, формулы (KaTeX локально), таблицы книги (прокрутка внутри), частая ошибка, что это значит для данных (гипотезы помечены), аналогия с границей, источник («стр. N» у каждого абзаца, цитаты автора, метка «автор / модель»), задачи из книги, иллюстрации, видео/интерактив.
- Карточки «знаю / повторить», конспект (суть + выводы для данных) с `@media print`, карта связей (SVG из `links`).
- Навигация: путь по главе, оглавление страницы шага, «назад / дальше», прогресс, ссылка «к содержанию» для клавиатуры.
- Таблицы книги целиком; исправления распознавания помечены в самой таблице (из `ocr_fixes`) и собраны в лист опечаток курса.
- Ролик стоит на своём шаге, с отключаемыми субтитрами (`.vtt` от П4 через `<track>`); если ролика нет — интерактив + ссылка на паспорт со спецификацией сцены.
- 390 px и 1280 px без горизонтальной прокрутки, светлая/тёмная тема (`prefers-color-scheme` + переключатель), текст ≥16 px, строка ~70 знаков, alt, видимый фокус, `prefers-reduced-motion`, ≤30 МБ на главу.

### 1б. Фишки, встроенные в шаблон сразу (см. `docs/product.md`)
- «Проверь по книге»: «стр. N» открывает окно с цитатой и сканом страницы (`data/pages/<ch>/p<N>.png`, ужать до ~100 КБ и скопировать в курс), отметка из отчёта П2, сверена ли цитата.
- Переключатель «автор / модель»: подсветка цитат автора, текста модели и гипотез.
Фишки 3–6 — только после того, как обязательный курс трёх глав готов (см. задачу 5б).

### 2. Текст шагов — до 22:00
- `prompts/course/step_page.md`: из полей узла → текст блоков. Фразы до 20 слов, термин выделен и объяснён при первом упоминании, суть 2–3 фразы. Ничего не добавлять сверх утверждений узла; каждый абзац ссылается на `claim_ids` (отсюда «стр. N»). Результат положи в `node.ext["course"]` в своём выходе, `layer.json` не меняй.
- Числа только из узла — П2 проверит.

### 3. Задания — до 22:00
- `prompts/course/tasks.md` → `out/<ch>/course/tasks.json` строго по `task.schema.json` организаторов (модель `Tasks`): ≥15 на главу, все 5 типов `single / multiple / order / gap / calc`, у каждого `step_id` (= id узла) и `claim_ids`; неверные варианты строятся на заблуждениях (`options[].misconception` = `misc.*`); поле `kind` (recall/understanding/transfer/data) заполнять — хотя бы одно `data` на главу; ответ есть в тексте шага. Расчёт — только по формулам и числам главы; ответ считается кодом (Python), а не моделью.
- Проверка сразу, после — верный ответ и пояснение в одну фразу. Порядок — перетаскивание пальцем (pointer events) + кнопки ↑↓ для клавиатуры.

### 4. Иллюстрации — до 02:00
- `pipeline/illus/run.py --ch` → `out/<ch>/illus/` + список `Illustration`. ≥1 на шаг, ≥1 класса A/B на часть.
- Генераторы кодом (matplotlib/SVG) по типу трудности: схема причинно-следственной цепочки из утверждений (класс B, «схема»), кривые и графики из формул главы (A/B, «симуляция»), колонка слоёв / разрез по стилю из доменного пакета, таблица-кроссплот. Рисунок книги, на котором держится пример, — перерисовка кодом с подписью «перерисовано по рис. N, стр. M».
- Генеративных картинок не делаем, кроме, по желанию, класса C/D с меткой «иллюстрация ИИ» на самой картинке и без керна, шлифов, схем, графиков, надписей.

### 5. Интерактив — до 06:00
Для узлов, которым маршрутизация дала видео, но ролика нет: JS-интерактив из той же модели (слайдер времени → давление; слайдер глубины → кривая; слайдер времени → рост слоёв). Шаблоны — общие по типу, не под главу. Шаг «решение на данных» (признаки → правило → вывод) хотя бы один на главу.

### 5б. Фишки 3–6 (`docs/product.md`) — после обязательного курса трёх глав, до 06:00
- **«Сначала угадай»** (после 02:00): если у узла есть `misconception`, шаг открывается одним вопросом «как думаешь?» с вариантами «верно / неверно»; после ответа раскрывается объяснение. Вопрос генерируется тем же промптом, что задания, и не входит в обязательные ≥15.
- **Ошибка → подсказка → абзац** (после 02:00): у неверного ответа кнопка «перечитать» прокручивает к абзацу шага с первым из `claim_ids` задания и подсвечивает его; узел ошибочного задания автоматически отмечается «повторить» в карточках (localStorage).
- **«Где здесь ИТ-задачи»** (к 06:00): отдельная страница главы — по каждому шагу `inefficiency` (входные данные, ручные шаги, точки суждения, время, типичные ошибки), `data_meaning` (гипотезы помечены) и `it_analogy` с границей; у каждого пункта ссылка на шаг.
- **Паспорт доверия** (к 06:00): страница главы из `out/<ch>/verify/trust.json` (делает П2) — покрытие, цитаты и числа сверены, замечания, ручные минуты, стоимость. Если файла нет — страницу не показывать, не падать.

### 6. Проверка на людях — утро
Дай курс и оба ролика 2–3 знакомым без геологии. Запиши, сколько задач решили (цель ≥80%), ответили ли на вопрос-предсказание и вопрос на перенос в роликах, где застряли. Задачи для них — как у панели жюри: «найди, почему…», «проверь утверждение по оригиналу». Это «доказательство эффекта» на защите. Ты же собираешь презентацию к защите.

## Контрольные точки
- 18:00 — курс по fixtures открывается на телефоне и десктопе.
- 22:00 — полный курс одной обучающей главы с заданиями.
- 02:00 — три главы, иллюстрации.
- 08:30 — курсы контрольных глав без правок кода под них.

## Нельзя
Менять `layer.json` и чужие зоны; верстать руками под конкретную главу; вставлять рисунки книги как картинки.
