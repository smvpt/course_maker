# П4 — видео и шаблоны сцен (роль в команде: дизайн / моушн)

Сначала прочитай корневой `CLAUDE.md` — там границы и интерфейсы. Твоя зона там же, строка «Видео».
Ролик собирается из двух JSON — `Script` и `SceneSpec` — по шаблону сцены. Никакого ручного монтажа: на тесте ролик на назначенный организаторами узел должен собраться командой.

## Баллы, за которые ты отвечаешь
Видео (10) + ролик на тесте внутри «двойников» (30) и «сдвига» (5) + пересборка ролика после правки факта (часть из 5). Одна критическая ошибка в ролике обнуляет его, две — лишают призового места.

## Что тебе нужно от других и где взять
- Узел и маршрут — `layer.json`, `routing.json`; образец — `fixtures/core/mini_chapter/` (до появления — свой в `fixtures/video/`).
- Проверка сцены — `pipeline.verify.scene` (П2, к 21:00); до этого просто валидируй контракт.
- Цвета и словарь ударений — `pipeline.common.domain.load(domain)`.

## Форматы организаторов (обязательно, см. `CLAUDE.md` §1б)
- Паспорт — `out/<ch>/videos/<video_id>/passport.json` по `passport.schema.json` (`Passport`): `script[]` с `t_start/t_end/text/claim_id/is_analogy/on_screen`, `sources[]` (`claim_id` → `page_or_dataset` + цитата), `scene_spec` = путь к `scene_spec.json`, `frames[]` (`t`, `class`, `label` — только «реальные данные/симуляция/схема»), `exaggerations`, `prediction_question`, `transfer_question`, `data_it_bridge`, `physics_checklist[]` (каждый пункт `pc.*` из `physics_checklist.json` с ответом «да/нет/н/п»), `audio_check` (темп, LUFS, рассинхрон, WER, «проверить на слух»). Сериализация с `by_alias=True` (поле `class`).
- Стайлгайд организаторов (`03_стайлгайд/styleguide.json`, `legend.html`): цвета брать из файла; подписи на кадре 1080 px — не мельче 44 px; безопасная зона 9:16 — 220 px сверху, 380 px снизу, 70 px по бокам; русская школа ГИС (ПС, ГК, КС, НГК, ГГК-П, АК), западные обозначения — только с названием школы в кадре; полярность сейсмики указывается (по умолчанию нормальная SEG); неопределённость — серая штриховка или диапазон.
- Планка качества и приёмы — `06_подача_и_референсы/разборы_4_роликов.md`: прочитай до шаблона T1.
- `domain/<домен>/templates/` — твоя подпапка: параметры шаблонов сцен по типам трудности (какой шаблон закрывает какой тип, параметры по умолчанию). Код шаблонов — в `pipeline/video/`, он не знает геологии.

## Задачи по порядку

### 1. Скелет видео — до 16:00
Установить Manim CE, edge-tts, ffmpeg, faster-whisper (версии в `requirements/video.txt`, `manifest/video.md`). «Hello-ролик» 9:16 из `Script` на 2 фразы: edge-tts по фразам (голос `ru-RU-DmitryNeural`, запасной `ru-RU-SvetlanaNeural`, ударения из `domain/<d>/stress_dictionary.md` и `pronunciation.md`), тайминги слов → субтитры, **длительность звука задаёт `run_time` анимации**, ffmpeg: склейка, `loudnorm=I=-16`, H.264. Кэш TTS в `cache/tts/`.

### 2. Генерация сценария и спецификации — до 19:00
`pipeline/video/spec.py --ch --node`: LLM → `Script` (крючок в первые 3 с — вопрос/парадокс; проблема → решение → название; пауза на предсказание; данные в кадре; решение специалиста; вопрос на перенос; фразы ≤15–18 слов, числа словами; каждая фраза с `claim_id`) и `SceneSpec` (шаблон, параметры, объекты, инварианты, допущения, преувеличения с числом, класс и метка каждого кадра). Шортс 40–75 с, разбор 1,5–3 мин.

### 3. Шаблоны сцен с одной моделью состояния
Каждый шаблон — класс Manim, читающий `SceneSpec.params`; одна переменная (ValueTracker) управляет и изображением, и графиком. Формат кадра из `--format`: 1080×1920 или 1920×1080.
- **T1 «волна давления»** (Ф, М) — до 21:00. Пласт окрашен давлением p(r,t) из решения уравнения пьезопроводности, рядом график p(r) в тот же момент; радиус влияния растёт как √t (а не линейно, как звук). Обязательный шортс 9:16 по Басниеву.
- **T2 «каротаж»** (И, Пр, Н) — до 21:00. Ствол, прибор на кабеле, пласты; глубина-трекер двигает прибор и рисует кривые из LAS (Volve, `lasio`); правило «сопротивление + пористость → насыщение». Обязательный разбор 16:9 по Латышовой («решение на данных»). Если Volve ещё нет — синтетический LAS с меткой «симуляция».
- **T3 «рост тела»** (Р, В, П) — до 04:00. Накопление слоёв во времени, проградация, синхронно разрез + план.
- **T4 «ствол скважины»** (бурение, для сдвига) — до 06:00. Гидростатика p = ρgh, газ в закрытой и открытой скважине по чек-листу ТЗ.
Оборудование — SVG по фото-референсам (`assets/video/`), не прямоугольники. Метка происхождения в углу каждого кадра. Не больше 7–8 слов на экране, ≥1,5 с на подпись, безопасная зона.

Обязательное для каждого шаблона (пункты с (О) в ТЗ — без них ролик теряет баллы или обнуляется):
- плашка «не в масштабе» с названием, что и во сколько увеличено; хотя бы один кадр в истинном масштабе (`true_scale_shot_id`);
- стрелка «сигнал → вывод»: наблюдение отделено от интерпретации; правило с контрпримером, если он есть в узле;
- пауза 1–1,5 с перед ответом на предсказание, финальное состояние держится на экране, в конце вопрос на перенос, итоговая карта шагов;
- шаг каждые 3–5 с, затемнения не длиннее 0,5 с, без формул и греческих букв в подписях, таблицы и формулы — не в шортс;
- одно обозначение — одно значение во всей серии; выбранная школа обозначений названа в кадре; цвета — из `styleguide.json` доменного пакета;
- 9:16: планшет ГИС вертикально, разрезы перекомпонуются или ведутся камерой, а не сжимаются; 16:9: разрез, кривые и шкала решения рядом;
- исторический прибор помечен «исторический прибор».

Дают баллы (стандарт качества, без (О)): один непрерывный мир без хаотичных склеек, мини-карта текущего шага при смене масштаба; синхронные виды (разрез + поверхность + план), если процесс на нескольких масштабах; кривая или число в кадре синхронно с процессом; финал — действие специалиста на данных или вопрос «как это автоматизировать»; масштаб привязан к знакомому («как N Останкинских башен») с оговоркой, что аналогия не передаёт; откуда доверие к числу (калибровка, керн, соседняя скважина); если два разных случая дают похожие данные — это сказано.

Озвучка (раздел «Озвучка» ТЗ):
- темп 110–150 слов/мин, один голос и один темп на всю серию; при отказе голоса заменяется голос всей серии;
- **запасной путь синтеза — другой сервис или локальный голос** (не просто второй голос Microsoft): бесплатный онлайн-синтез может отказать по частоте;
- −16 LUFS без клиппинга, музыка (если есть) −20 дБ под голосом, фраза не обрезается концом;
- на экране ключевые слова, полный текст — в **отключаемых** субтитрах: рядом с mp4 кладётся `.vtt`, курс подключает его через `<track>`;
- локальное распознавание (faster-whisper): ошибки слов ≤10%, термины без искажений; темп, громкость и рассинхрон пишутся в паспорт; спорные ударения — в список «проверить на слух» для ментора.

### 4. Цикл одного ролика (`video.build --node`)
spec (если нет) → `verify.scene` → TTS → рендер (`--draft` = `-ql`) → субтитры → ffmpeg → whisper сверяет дорожку со сценарием → кадры по одному на shot в `frames/` → `passport.json` (по `passport.schema.json`) (карточка узла, сценарий с таймкодами, таблица источников «утверждение → страница/датасет», спецификация, классы кадров, преувеличения, вопросы, мост к данным). Пересборка после правки факта — той же командой.

### 5. Менторы — к 22:00
Сдать менторам обе спецификации (T1/Басниев, T2/Латышова) с таблицей источников. Финальный рендер — только после их ответа.

### 5б. Спецификации для ВСЕХ видео-узлов
ТЗ: в главе без ролика узлы, которым маршрутизация дала видео, закрываются в курсе интерактивом или анимацией, «а спецификация сцены лежит в паспорте». Значит `video.spec` + `passport.json` (по `passport.schema.json`) (без mp4) делаются для каждого видео-узла каждой главы; рендер — только для двух обязательных роликов и назначенного узла на тесте. Цель `make all` вызывает `video.spec` для всех видео-узлов.

### 6. Отчёт о покрытии шаблонами
`python -m pipeline.video.coverage --ch` → по каждому видеоёмкому узлу: какой шаблон с какой моделью состояния его закрывает или «нужен новый». Нужен на тесте.

## Как работать с агентом
Агент не видит видео — смотришь ты. Черновик `-ql`, кадры `ffmpeg -vf fps=1 frames/%03d.png`, показывай агенту конкретный кадр и что не так. Одна сессия — один шаблон. Финальные рендеры запускай в фоне и параллельно делай следующий шаблон.

## Контрольные точки
- 16:00 — hello-ролик с синхронной озвучкой.
- 22:00 — обе спецификации у менторов, черновики T1 и T2.
- 02:00 — финальные ролики обучения + паспорта.
- 08:30 — `video.build` на узле контрольной главы без правок кода.

## Нельзя
Генеративное видео/картинки в кадрах A и B; цифры и текст от генеративной модели; ручной монтаж; менять чужие зоны.
