## Форматы организаторов (обязательно, см. `CLAUDE.md` §1б)
- `layer.json` — по `node.schema.json`: поля `why_here`, `difficulty.primary/secondary`, `layers.topic/main/mechanism/practice/nuances/deeper`, `claims[].page_pdf/quote/source_kind/by_model`, `data_meaning.from_chapter/breaks/hypotheses`, `it_analogy`, `inefficiency_lens`, `terms_introduced/terms_used`, `needs_scan`, `decision_on_data`, `worked_examples`, `book_tasks`, `pages`. Образец — `data/organizers/01_схемы/example_layer.json` (и копия в `fixtures/core/example_layer_organizers.json`).
- `coverage.json` (не CSV) — по `coverage.schema.json`: `unit_id` вида `p095.03`, `kind`, `page_pdf`, `excerpt` (5–15 слов), `node_ids`, `reason` («непоказуемо» — не причина).
- `routing.json` — по `routing.schema.json`: `format` по-русски («шортс», «длинное видео», «интерактив», «практикум на данных», «карточки», «текст»), `video_scores` 0–2 по пяти критериям, `hook_short`, `template`, `why`.
- id главы — латиницей в нижнем регистре, как у организаторов: `latyshova_gl5_par17-20`, `basniev_gl23-24`, `kuznetsov_gl10`, `vendelshtein_gl1`, `barenblatt_par4`, `baraboshkin_par1-2`.
- Связь `refutes_misconception` ведёт на `misc.*` из `domain/geology/misconceptions.json`; `to_data` — на `data.*`.
- Опора для промптов: `06_подача_и_референсы/подача_доменов_геологии.md` (8 типов трудности, формат-микс, 48 концептов) — для маршрутизации и порядка; `04_доменные_заготовки/портреты_зрителя.md` — для `data_meaning` и `it_analogy`.
- Контрольный пакет организаторов содержит свой md только с главой (`vendelshtein_gl1.md`, метки страниц сохранены) — ingest должен принимать и целую книгу с диапазоном страниц, и md одной главы.
- Первая задача после `llm.py`: `tests/core/test_schemas.py` — `jsonschema.validate` каждого выхода по файлам из `data/organizers/01_схемы/`. Без зелёного теста ничего в main.

## Задачи по порядку

### 0. Разблокировать команду — до 14:30
1. Скелет репозитория по таблице зон: пустые пакеты с `__init__.py`, `Makefile` с `include mk/*.mk` и целями `install test smoke all rebuild check video`, `requirements.txt` с `-r requirements/*.txt`, `.gitignore` (`.env`, `out/`, `data/pages/`, `__pycache__`), `.env.example`.
2. `contracts/models.py` — уже есть черновик, проверь импорт и тест на сериализацию.
3. `pipeline/llm.py` строго по интерфейсу из `CLAUDE.md` §2: провайдер через litellm, `config/llm.yaml` (модели для tier `default`/`strong`/`vision`, цены), кэш `cache/llm/<sha256>.json`, `LLM_OFFLINE=1`, лог `out/_metrics/llm_calls.jsonl`, валидация pydantic + 2 повтора.
4. `pipeline/common/`: `paths.py` (пути out/data по chapter_id), `io.py` (load/save моделей), `domain.py` (`load(domain)` читает `domain/<domain>/`), `config.py`.
5. `config/chapters.yaml`: для каждой главы — id, файл md, PDF, диапазон страниц PDF, язык, домен. Обучающие: Латышова 90–108, Басниев 474–500, Кузнецов 200–222. Контрольные: Вендельштейн 9–14 и 20–30, Баренблатт 38–51, Барабошкин 30–44. Тестовые добавляются строкой конфига. Необязательные поля главы: `prereading` (короткое чтение к обучающим главам), `prereq_cards` (карточки-предпосылки к контрольным и тестовым), `errata` (лист опечаток распознавания). ТЗ: тестовые главы выдаются ВМЕСТЕ с карточками-предпосылками и листом опечаток — конвейер обязан их принять без правки кода: ingest применяет опечатки (и помечает исправления для таблиц), structure считает термины из предпосылок уже известными и ставит на них связь «предпосылка».
Промпты структурирования опираются на эталонный атом организаторов («Сейсмика — не фотография») как образец узла и на портреты зрителя (цифровики) — положи их в `data/organizers/` и подставляй в промпт, когда появятся.
6. `fixtures/core/mini_chapter/`: 3 страницы из `data/books/ctrl_barenblatt.md` + готовые `units.json`, `layer.json` (2 узла, заполнены все поля), `routing.json`. Это корм для тестов П2–П4. **Сделать первым после llm.py.**

### 1. Ingest → `units.json`
- Режет md по меткам `<!-- page N -->`, берёт только страницы главы из конфига.
- Делит на единицы: заголовок, абзац, список, рисунок (подпись «Рис./Fig.»), формула (`$$`, `\[`), таблица (markdown-таблица), пример, задача. Склеивает абзацы, разорванные переходом страницы.
- Рендерит страницы PDF в `data/pages/<ch>/p<N>.png` (`pdftoppm -r 110`). Для единиц-рисунков vision-моделью — описание рисунка и легенды в `text`.
- Должно работать на английском тексте и на главе без формул/таблиц.

### 2. Structure → `layer.json` + `coverage.json`
- Этап A (strong): по единицам главы — план узлов: id, порядок, тип трудности, `unit_ids`, обоснование порядка. Порядок «для неспециалиста»: термин раньше употребления.
- Этап B (strong, по узлу): заполнить все поля `Node` из текста его единиц. Утверждения — с дословной цитатой и страницей. Не сжимать: все мысли автора, все примеры и задачи.
- Цикл покрытия: единицы без узла → дозапрос «куда это или почему нет». Цель — 0 непокрытых без причины.
- Цикл цитат: вызвать проверку цитат П2 (`pipeline.verify.quotes`, если уже есть; если нет — пропустить с предупреждением). Не найденная цитата → дозапрос «дай дословно с этой страницы».
- Устойчивые id: slug от `title_book`, при повторном прогоне не меняются (кэш).

### 3. Route → `routing.json`
Правила по типу трудности + LLM-обоснование по 5 критериям видеоёмкости. Шаблоны сцен: `T1` давление/фильтрация (Ф, М), `T2` каротаж (И, Пр, Н), `T3` рост тела/слоёв (Р, В, П), `T4` ствол скважины (бурение). Видео нужно не всем узлам.

### 4. Сборка и пересборка
- `make all CH=x`: ingest → structure → route → verify → illus → course → (видео для узлов с видео-форматом, если задан `VIDEO=1`).
- `make rebuild NODE=id`: после правки `layer.json` руками пересобрать страницу шага (`course.build --node`) и ролик (`video.build --node`), если он есть.
- `make smoke`: весь путь на `fixtures/core/mini_chapter` с `LLM_OFFLINE=1`, < 3 мин.

### 4б. Живая демонстрация пересборки (фишка 7, репетиция до 09:30)
Скрипт `scripts/demo_rebuild.sh <ch> <node_id>`: показывает утверждение узла → меняет в `layer.json` одно число или формулировку (копия слоя, оригинал не трогаем) → `make rebuild NODE=<id>` → открывает страницу шага и печатает путь к новому ролику. Ролик для демо — узел шортса (короткий рендер). Прогони 2 раза, замерь время, запиши в `docs/run.md`.

### 5. К заморозке (до 09:30)
`docs/run.md` (запуск жюри с нуля: клон → `make install` → `LLM_OFFLINE=1 make all CH=...`; для `make rebuild` после правки факта нужен ключ — как его задать в `.env`; перечень моделей и как заменить модель — переменная `LLM_MODEL` в `.env`, как в шаблоне манифеста организаторов), `docs/playbook.md`, сборка `MANIFEST.md` (по `MANIFEST_template.md` организаторов) из `manifest/*.md`, метрики `metrics.csv` строго по шаблону организаторов (`MetricsRow`: строка на главу и этап layer/routing/course/video/review — токены, деньги, человеко-минуты, минуты ментора, секунды видео, доля ручного труда; из `llm_calls.jsonl` и журнала П2) + `out/_metrics/summary.md` со стоимостью узла, главы и минуты видео, кэш в git, тег `v1.0-freeze`.
